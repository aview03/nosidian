# 휴대폰 연결 (PC AI 중계)

PC 앱과 폰 앱을 함께 쓸 때, 폰이 PC 의 AI 를 쓰게 한다. 기본은 꺼짐.

## 흐름
1. PC 설정 > AI > "휴대폰에서 이 PC의 AI 쓰기"를 켠다 → 같은 와이파이(사설망)에서만 듣는 서버(기본 47410)가 열린다.
2. 폰 설정 > AI > "내 PC에 연결" → QR 스캔 또는 `ip:포트/코드` 입력. 코드는 6자리, 5분, 한 번만. 5번 틀리면 1분 잠금. 기기는 최대 5대.
3. 짝이 맺히면 폰은 토큰을 받는다(PC 는 해시만 보관). PC 설정에서 언제든 해제.

## 무엇을 중계하나
- **모델**: `/api/*`(Ollama), `/v1/*`(OpenAI 호환)를 PC 의 AI 서버로 전달. PC 에 저장된 API 키는 PC 가 자리표시자로 주입 — 폰은 키를 모른다.
- **Claude 구독**: `/claude/run → poll → end`. PC 의 Claude Code 가 돌고, 노트 도구 호출(`toolcall`)은 폰으로 되돌려 보내 **폰의 노트에서 실행**한다(`/claude/tool`). 묻기=읽기 전용, 변경 제안은 폰의 정책·승인 흐름.

## 보안 메모
- 사설 주소(192.168/10/172.16-31/169.254/100.64/로컬)에서 온 요청만 받는다. 모든 요청에 Bearer 토큰 필요. 본문 8MB 제한.
- 통신은 http(암호화 없음) — 같은 와이파이 안에서만, 공용 와이파이에서는 끈다.
- 폰의 노트 내용이 PC 를 거쳐 선택한 AI 제공자(Claude/OpenAI 등)로 전달된다.

## 코드
`electron/aiRelay.cjs`(서버) · `src/lib/pcLink.ts`(폰 클라이언트) · `RelayCard.tsx`(PC UI) · `QrScan.tsx`(폰 카메라+jsQR) · `relayBridge.ts`(AI 설정 → 메인).
