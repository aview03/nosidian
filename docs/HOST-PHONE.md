# 폰의 "내 PC" 연결 (v1.42)

PC 앱이 호스트(`docs/HOST-STORE.md`·`docs/HOST-SERVER.md`)일 때, 폰이 **클라우드 없이** 같은 와이파이에서 Vault 를 PC 와 맞춘다. 기존 클라우드 동기화(GitHub·Drive·OneDrive)와 AI 정책·승인 기능은 건드리지 않았다.

## 구성
- `src/lib/pcHost.ts`: 연결 문자열 `nsh1:…` 해석, 짝 맺기, **PinnedHttp**(인증서 지문 고정) 호출, 주소 재탐색, 오류 문장. 연결 정보는 `nosidian.pchost`(주소·지문·이름·기기 ID)에 두고 **토큰은 Android Keystore**(v1.39)에 둔다.
- `src/lib/sync/pchost.ts`: **기존 `Provider` 인터페이스**를 구현한 "내 PC" Provider. 동기화 엔진(받기 → 병합 → 올리기, `mergeNote`, 409 재시도)은 클라우드·PC 폴더와 같은 코드다. 새 엔진 없음.
- `src/lib/hostConnect.ts`: 최초 연결(미리보기 → 승인 → 스냅샷 → 반영)을 PC 폴더 연결과 폰 연결이 함께 쓴다(`HostIO`: PC 는 IPC, 폰은 HTTPS).
- `src/lib/phoneSnapshot.ts`: 폰 스냅샷(앱 전용 파일). `src/components/PcHostConnect.tsx`·`HostPlan.tsx`: 화면.
- 서버 추가(`hostServer.cjs`): `/ping` 이 PC 의 현재 주소 목록을, `/snapshot` 이 최초 연결 직전의 호스트 폴더 스냅샷(쓰기 허용 기기만, 1분에 한 번)을 준다.

## 동작 규칙
- **기기 식별은 기기 ID + 인증서 지문**, IP 는 힌트다. 마지막 성공 주소 → 알려진 후보 순서로 시도하고(네트워크 실패일 때만), 성공하면 PC 가 알려 주는 현재 주소로 후보를 갱신한다. **지문이 다르면 자동으로 다시 연결하지 않는다.**
- **쓰기 권한이 없으면(기본)** 받기만 하고 "받기만 했어요. 이 PC에서 이 휴대폰의 쓰기를 허용하면 내 변경도 올라가요"로 안내한다(실패가 아니다). 폰의 변경은 그대로 남아 있다가 PC 가 허용한 뒤 올라간다.
- 올리기는 **조건부**(마지막으로 본 rev). PC 에서 먼저 바뀌었으면 409 → 한 번 다시 받아 합친 뒤 올린다(Markdown 은 `mergeNote` 줄 단위 병합, 같은 줄이면 충돌 표시·PC 파일은 덮어쓰지 않음).
- **삭제는 PC 로 전파되지 않는다**(삭제 권한은 꺼져 있다). 폰에서 지운 파일은 다음 동기화에서 PC 에서 다시 받아지며, 그 사실을 알린다. PC 에서 지운 파일은 폰의 깨끗한 사본이 로컬에서 지워지고(되살리지 않음), 폰에서 고치던 파일은 살려서 다시 올린다(삭제 vs 수정 → 수정 유지).
- 실행 파일은 폰에서 올릴 수 없고 이유를 알려 준다(PC 가 거부). 오프라인이면 실패로 알리지만 로컬 노트는 그대로이고, 연결되면 올라간다.
- 동기화가 끝나면 이 폰이 여기까지 반영했다는 확인(ack)을 PC 에 남긴다(삭제 기록 정리 조건).

## 최초 연결
1. 설정 > 노트와 동기화 > 연결하기 > "내 PC (클라우드 없이)" → QR 스캔 또는 연결 문자열 붙여 넣기(PC 앱 "휴대폰과 맞추기"를 켜야 나온다).
2. **미리보기**(읽기만): 폰에만 / PC 에만 / 같음 / 다름 / 노트가 아닌 파일 / 지워졌던 경로(되살아남 경고). 내용이 다른 항목은 **항목별로** 고른다(기본 선택 없음). 읽기 전용이면 "PC 것으로 올리기"는 고를 수 없고, 올릴 노트는 "올리기 대기"로 남는다.
3. 시작: **스냅샷 먼저** — 폰의 노트(앱 전용 파일, 쓰고 다시 읽어 확인) + 쓰기가 허용되면 PC 호스트 폴더. 하나라도 못 만들면 **시작하지 않는다**. **삭제는 없다.**
4. 되돌리기: "PC 연결 끊기"(노트 그대로, 연결 정보·토큰만 지움) · "스냅샷에서 복원".

## 한계·미확인
- **QR 카메라 스캔은 이번에도 하지 못했다**(붙여 넣기로 연결). "스냅샷에서 복원" 버튼은 폰에서 직접 눌러 보지 못했다(단위 시험으로만 확인).
- 바이너리(.docx 등) 충돌의 "내 것 새 이름으로 / PC 것 유지 / 덮어쓰기" 선택 화면은 **만들지 못했다**: 현재는 409 를 "PC에서 먼저 바뀌었어요"로 알리고 덮어쓰지 않는다.
- 주소 후보가 모두 죽어 있으면 첫 주소에서 약 8초(네이티브 연결 제한 시간) 걸린 뒤 다음 후보로 넘어간다. 이후 동기화는 성공한 주소를 먼저 쓴다.
- 연결 정보(`nosidian.pchost`)는 기기에 하나뿐이다(여러 Vault 에 서로 다른 PC 를 연결할 수 없다). 삭제 전파·삭제 권한은 아직 없다.
- 자동 동기화(앱을 켤 때·주기)는 만들지 않았다 — "지금 동기화"를 누르거나 기존 동기화 트리거를 쓴다.
