# 정보 구조(IA) 개편안 — 설정·AI 연결·온보딩·내 업무 타일·메모 (v1.30 설계, 미구현)

페르소나·시나리오: [UX-PERSONAS.md](UX-PERSONAS.md). 이 문서는 구현 전 **승인용 설계**다. 화면 와이어프레임은 구조만 보여 주며 시각 디자인(색·간격)은 기존 토큰을 쓴다.

## 0. 현재 문제 (실제 화면 기준)
설정 카드 12개가 구현 순서대로 평평하게 쌓여 있다: Vault → 동기화 → 폰 위젯 → 업무(내 이름) → AI 연결 → 앱 안 AI → 외부 AI(MCP) → AI 자동 문서 관리 → 캘린더 → 화면 → 단축키 → 바탕화면 위젯.
- 같은 목표(AI)가 카드 4개로 흩어지고, 방식 이름이 기술 용어(MCP·CLI)다.
- 첫 실행 화면이 곧바로 "GitHub / Google Drive / OneDrive 연결"을 묻는다(동기화부터 고르게 하는 구조).
- 내 이름은 설정 중간, 모바일에도 PC 단축키·위젯 버튼이 보인다.

## 1. 설정 구조: 6개 그룹, 위에서 아래로 "자주 → 드물게"
```
설정
 ├─ 내 프로필           이름 · 내가 하는 일(페르소나) · 언어           ← 맨 위
 ├─ 노트와 동기화       내 노트 보관함(vault) · 다른 기기와 맞추기
 ├─ AI                 AI 연결하기 · 자동 문서 관리
 ├─ 화면               테마 · 글자 크기 · 캘린더 옵션
 ├─ 업무와 문서         내 업무 홈 구성 · 문서 규칙
 └─ 정보·고급          단축키(PC) · 외부 AI 연결(MCP) · 바탕화면 위젯(PC) · 버전
```
- **PC**: 왼쪽 그룹 목록 + 오른쪽 상세(2단). **모바일**: 그룹 목록 → 한 그룹 화면(드릴다운, 뒤로 가기).
- 각 그룹 화면은 "핵심 1~3개 항목"만 먼저 보이고, 나머지는 **고급 ▸** 로 접는다.
- 모바일에서 숨김: 단축키, 바탕화면 위젯, MCP(PC 전용 기능), 홈 화면 위젯 추가 버튼(삭제). 
- 삭제: "홈 화면 위젯 추가" 버튼(위젯은 홈 화면 길게 눌러 추가하는 일반 방법으로 충분).

## 2. 내 프로필 (설정 맨 위 + 첫 실행에서 받음)
```
내 프로필
  이름            [ 민수            ]   할 일의 담당자·내 업무 필터에 쓰여요
  내가 하는 일    ( ) 디자이너 ( ) 기획자 ( ) 개발자 ( ) 마케터 ( ) 연구자 ( ) 학생 ( ) 잘 모르겠어요
                  → 내 업무 홈의 기본 구성이 달라져요   [내 업무 구성 다시 고르기]
  언어            한국어 ▾
```
- 이름은 쉼표로 여러 개(별명) 허용 — 현재 동작 유지. 입력 UI는 칩(chip)으로 "별명 추가"로 순화.

## 3. AI 연결: 한 곳, 목표 중심, 기술은 고급으로
진입: 설정 > AI. 화면 첫 줄은 상태 한 줄, 아래는 **"AI 연결하기"** 한 개의 카드.

```
AI
  ┌ 지금 상태 ─────────────────────────────────┐
  │ ✓ Claude Code(내 Claude 계정)로 연결됨        │   [바꾸기]
  └──────────────────────────────────────────┘
  (연결 안 됨이면)
  AI 를 어떻게 연결할까요?
  ┌ 내 구독 계정으로  (추천: 이미 Claude/ChatGPT/Gemini 를 쓴다면)
  │   Claude Code · Codex · Antigravity ── PC 에 설치돼 있고 로그인돼 있으면 한 번에 연결
  ├ 내 컴퓨터에서 돌리기  (무료 · 문서가 밖으로 나가지 않아요)
  │   Ollama · LM Studio
  └ API 키로 연결  (GPT · Gemini · Claude)
      키를 붙여 넣으면 끝. 키는 이 기기에만 저장돼요
  ▸ 자동 문서 관리 (AI 가 새 문제를 알아서 살펴봐요)
  ▸ 고급: 다른 앱의 AI 가 내 노트를 쓰게 하기 (MCP)
```
- 카드를 고르면 **3단계 이내 마법사**: ① 방식 고르기 ② 준비 확인(자동 감지: 설치·로그인 여부, 서버 연결) ③ "테스트 질문 한 번" 으로 성공 확인.
- 용어: MCP → "다른 앱의 AI 가 내 노트를 쓰게 하기", CLI → "내 구독 계정으로", 엔드포인트 → 고급 안에서만.
- 연결 방식 지원 현황: ① 구독 계정(Claude Code 가능 / **Codex·Antigravity 는 미구현 → "준비 중" 표시**) ② 로컬(Ollama·OpenAI 호환 가능) ③ API 키(OpenAI·Anthropic·Gemini 가능).
- 개발 범위 메모: Codex/Antigravity CLI 연결은 각 CLI 의 비대화형 출력·도구 연결 방식을 확인해야 하므로 별도 단계(자리만 마련).
- 모바일: AI 그룹에는 "AI 는 PC 앱에서 쓸 수 있어요" 한 줄과 자동 문서 관리 알림 요약만. (모바일 AI 패널은 이번 범위 밖)

## 4. 노트와 동기화: "다른 기기와 맞추기"
```
노트와 동기화
  내 노트 보관함   예제 노트 ▾   [새로 만들기] [이름 바꾸기]
  다른 기기와 맞추기
    ( 연결 안 됨 )   [ 연결하기 ]
  ▸ 고급: 충돌 처리 · 저장 위치 · 연결 해제
```
- "연결하기" → 마법사: ① 어디에 보관할까요? (Google Drive / OneDrive / GitHub, 한 줄 설명 + 이런 분께: GitHub=개발자) ② 로그인(OAuth) 또는 토큰 ③ 완료.
- 페르소나 추천: 개발자·연구자는 GitHub 이 위, 나머지는 Drive/OneDrive 가 위.
- 연결 후에는 상태 한 줄(마지막 동기화, 수동 동기화 버튼)만 보인다. 토큰·브랜치·저장소 이름은 고급.

## 5. 첫 실행(온보딩): 4화면, 동기화·AI 는 나중에
```
① 이름   "어떻게 불러 드릴까요?"                       [다음]
② 역할   "주로 어떤 일을 하세요?"  카드 6개 + "잘 모르겠어요"   → 내 업무 홈 기본 구성
③ 시작   [예제 노트로 둘러보기] [새로 시작하기] [md 파일 가져오기]
④ 완료   "오늘 할 일이 보여요" → 내 업무 홈 (연결·AI 는 홈 카드로 권유: "기기끼리 맞추기" "AI 연결" — 나중에/닫기)
```
- 지금의 첫 화면(동기화 버튼 3개)은 ③의 "기존 노트 연결" 아래 작은 링크로 이동.
- 홈의 권유 카드는 페르소나별 순서(개발자: 동기화 먼저, 기획자: 동기화 → AI, 학생: 없음).

## 6. 내 업무 타일 설정: 그룹 + 켜진 것 위
현재 타일 10개(오늘·기한 지난 일·결정할 일·오늘 마감·이번 주·기다리는 일·진행 중·담당자 없는 일·받은 업무·프로젝트)와 사용자 정의 타일이 하나의 목록이다.
```
내 업무 홈 구성                                     [완료]   ← 오른쪽 위(이미 수정)
  내 구성에서 시작:  ( 기획자 ▾ )  [프리셋 다시 적용]
  ── 켜 둔 타일 (끌어서 순서 바꾸기) ──
   ≡ 오늘 일정                 [5줄 ▾]  ⏻
   ≡ 기한 지난 일              [5줄 ▾]  ⏻
   ≡ 프로젝트                           ⏻
  ── 더 추가하기 ──
   오늘·일정   : 이번 주 · 오늘 마감                    [+]
   주의할 일   : 기다리는 일                            [+]
   협업·결정   : 결정할 일 · 담당자 없는 일              [+]
   진행·정리   : 진행 중 · 받은 업무                    [+]
   내가 만든 타일 : (사용자 정의)                       [+ 새 타일]
```
- 그룹(분류)은 앱이 정한다: **오늘·일정**(오늘, 이번 주, 오늘 마감) / **주의할 일**(기한 지난 일, 기다리는 일) / **협업·결정**(결정할 일, 담당자 없는 일) / **진행·정리**(진행 중, 받은 업무, 프로젝트).
- "켜진 것 위, 꺼진 것 아래" — 꺼진 타일은 그룹별 "더 추가하기" 목록에 있다(현재처럼 켜 놓은 순서를 훼손하지 않는다).
- 모든 타일에 "한 줄 설명"(예: 기다리는 일 = "내가 답을 기다리는 일")을 보여 주어 이름만 보고 고르지 않게 한다.
- 프리셋은 UX-PERSONAS 표대로. 사용자가 직접 바꾸면 프리셋은 "내 구성"으로 표시.

## 7. 메모(노트 편집) 단순화 — 가정 포함, 확인 필요
"메모부"를 **노트 편집 화면(툴바 포함)과 오늘 노트**로 가정한다. 확인할 부분은 질문 참고.
- 기본 툴바는 **굵게·기울임·체크박스·목록·링크** 5개 + "더 보기(⋯)"(제목, #태그, [[링크]] 삽입, 인용, 코드 …).
- 보기 모드 전환(편집/읽기/소스)은 기본 하나("편집")만 두고 나머지는 ⋯ 안. 개발자 프리셋만 소스 모드를 기본 노출.
- 새 노트 시작 시 빈 화면 대신 "이름만 쓰면 돼요"와 템플릿 3개(페르소나별).
- 속성(프런트매터)·role·태그 같은 구조는 노트 위쪽 접는 영역("노트 정보")에 숨기고, 문서 규칙을 쓰는 프로젝트에서만 펼침 권유.

## 10. 열어 둔 질문
1. "메모부"가 위 7번의 노트 편집·오늘 노트가 맞는지, 특히 무엇이 복잡했는지.
2. 페르소나 선택은 건너뛸 수 있게(= "잘 모르겠어요" → 현재 기본 구성) 해도 되는지.
3. 기존 사용자(이미 쓰는 사람)의 내 업무 구성은 **그대로 유지**하고, 프로필(역할)만 새로 물어볼지.

## 11. 결정 사항과 구현 현황 (사용자 확인 반영)
- **"메모부" = 모바일의 메모 탭(파일 목록)**. 삼성 노트처럼 오른쪽 아래 [쓰기] 버튼으로 빠르게 쓰고, 목록에서 **꾹 눌러 여러 개 선택 → 폴더로 넣기/꺼내기·이름 바꾸기·삭제**, **폴더를 꾹 눌러 폴더째 삭제·이름 바꾸기**를 제공한다(아래 12, v1.30.2 예정). 이전 7번(편집 툴바 단순화)은 후순위.
- 역할 선택은 **건너뛸 수 있다**("건너뛰기"). 기존 사용자의 내 업무 구성은 그대로 유지(역할은 null 로 시작).
- 설정에서 역할을 **바꿀 수 있고**, "역할에 맞춰 내 업무 화면 구성하기" 선택 옵션으로 **구성 자동 적용 여부를 정한다**. 꺼 두면 역할은 표시만 한다. [이 역할의 기본 구성으로 되돌리기] 버튼은 언제나 쓸 수 있다.
- **v1.30.0 구현**: 첫 실행 이름·역할(건너뛰기 가능), 설정 맨 위 "내 프로필"(이름·역할·자동 적용·되돌리기), 역할별 타일 프리셋(`lib/persona.ts`), 내 업무 타일 설정을 "켜 둔 타일(끌어서 순서) / 더 추가하기(분류 4개 + 한 줄 설명)"로 재편(켜진 것 위, 끈 것은 아래).

## 12. 모바일 메모 탭 개편안 (v1.30.2, 미구현)
```
메모                                   🔍  ⋮
┌ 폴더 ──────────────────┐
│ 📁 프로젝트  (12)       │   ← 폴더 행: 탭 = 열기, 꾹 = 선택 모드
│ 📁 Daily     (30)       │
├ 노트 ──────────────────┤
│ 환영합니다    11/10     │
│ 여행 결정 기록 11/09    │
                         ( ✎ )   ← 오른쪽 아래 [쓰기] 버튼: 새 노트(현재 폴더에), 제목은 첫 줄에서 자동
```
- **선택 모드**: 행을 꾹 누르면 선택 모드(체크박스 + 위 막대 "n개 선택"). 막대: **폴더로 이동 · 이름 바꾸기(1개 선택일 때) · 삭제 · 선택 해제**. 폴더 안에서는 "폴더 밖으로 꺼내기"(상위 폴더로 이동)가 이동 대화상자의 첫 항목.
- **폴더 꾹 누르기**: 폴더째 이름 바꾸기·삭제(삭제 전 "노트 n개도 함께 지워져요" 확인, 휴지통 개념이 있으면 거기로).
- 새 노트: [쓰기] 버튼 → 바로 편집 화면(키보드 열림). 목록에서는 폴더별 구분이 보이되 깊이는 한 번에 한 단계(드릴다운)로 단순화하는 안을 함께 검토.
- 안전: 이동·이름 바꾸기는 링크([[ ]])가 깨지지 않게 기존 이름 변경 로직(링크 갱신)을 재사용하고, 삭제는 확인과 되돌리기(스낵바)를 둔다.

- **이동 시트**: 맨 위/폴더 밖으로 꺼내기, 한 단계 위로 꺼내기, 폴더 목록(선택한 폴더 자신과 그 하위는 비활성), "새 폴더에 넣기". 폴더째 이동하면 안의 노트가 모두 따라가고, 같은 이름이 있으면 (2)를 붙여 덮어쓰지 않는다.
- **폴더 이름 바꾸기**: 안의 노트 경로가 모두 바뀐다. 같은 이름의 폴더가 이미 있으면 합치지 않고 거절. **폴더 삭제**: "폴더 안의 노트 n개도 함께 지워져요" 확인 후 삭제.

## 13. v1.30.3 구현 현황 (설정 6그룹 재편 + 글 줄이기)
- **그룹**: 내 프로필 · 노트와 동기화 · AI · 화면과 캘린더 · 업무와 문서 · 정보. PC 는 왼쪽 그룹 목록 + 오른쪽 내용(2단), 모바일은 그룹 목록 → 그룹 화면(뒤로 버튼). 각 그룹 목록 행에 지금 상태를 한 줄로 보여 준다(예: "민수 · 기획자", "예제 노트 · 이 기기에만").
- **정리**: 홈 화면 위젯 추가 버튼 삭제, 모바일에서 단축키·바탕화면 위젯·MCP 안 보임(AI 그룹은 "PC 앱에서 쓸 수 있어요" 한 줄), 내 이름은 프로필(맨 위)로, 버전은 정보에 표시.
- **동기화**: 연결 전에는 한 줄 안내 + [연결하기] 만 보이고, 누르면 "어디에 보관할까요?"(GitHub/Drive/OneDrive)와 입력칸이 나온다. 연결 후에는 상태 3줄 + [지금 동기화], 나머지(브랜치·연결 수정·해제·동작 설명)는 "고급"에 접는다.

- **글 줄이기**(PC·모바일 화면을 보며 검토): Claude 카드 5줄 → 2줄(기술 용어 MCP·파일·셸 설명 삭제), 자동 문서 관리 안내·모드 설명·동의 설명·시험 실행 설명을 한 문장으로, API 키·MCP 안내 축약. "고급 ▸" 접기 패턴으로 드문 항목을 숨김.

## 14. v1.30.4 보정 (사용 중 발견)
- **보호 폴더**: 메모 탭에서 프로젝트/Projects·날짜별 노트 폴더·`_workspace`·`_보관`·`Templates` 최상위 폴더는 삭제·이름 바꾸기·이동을 막고 이유를 알린다(안의 노트·하위 폴더는 가능). 프로젝트가 들어 있는 폴더를 지울 때는 "프로젝트 n개를 포함해 노트 m개가 모두 지워져요. 되돌릴 수 없어요"로 한 번 더 경고한다.
- **언어별 기본 폴더**: 처음 쓰는 사람은 한국어면 `할 일`·`프로젝트`, 그 밖은 `Tasks`·`Projects`(첫 실행에서 언어를 고른 뒤 정함. 기존 사용자의 `Daily` 설정은 그대로). 새 프로젝트는 이미 쓰는 최상위 폴더(프로젝트/Projects)가 있으면 그것을 쓴다. 예제 vault 도 같은 폴더에 만든다.
- 설정 > 업무와 문서 > "내 업무 화면 구성 편집"에서 들어가 [완료]하면 설정으로 돌아온다.
- 첫 실행: 이름은 건너뛸 수 없다(역할은 건너뛸 수 있음). 설명 문구를 모두 없애고 모든 단계를 같은 구성(구 + 질문 + 버튼)으로 맞춤.
- 모바일 메모: 손가락으로 꾹 누를 때 뒤따르는 `contextmenu` 가 선택을 다시 토글해 선택 모드가 꺼지던 버그 수정(테스트 추가).
- 내 업무: 타일마다 면(헤더 띠 + 배경 + 테두리)을 깔아 구분. 보관함 카드: 이름·상태 → [전환] → 보조 동작 → 고급(삭제)의 위계.

## 15. v1.30.5 앱이 쓰는 두 폴더의 규칙 (날짜 노트 폴더 · 프로젝트 폴더)
원칙: **사람이 직접 만들거나 옮길 때는 형식을 강제하고, 동기화·가져오기·AI 로 들어온 것은 막지 않고 정리하도록 안내한다.**
- **날짜 노트 폴더**(설정의 Daily 폴더: 할 일/Tasks/Daily): 새 노트를 만들려 하면(메모 탭 [쓰기], 새 노트 대화창) 이름을 받지 않고 **오늘 노트를 연다**(이미 있으면 그것). 날짜 이름(YYYY-MM-DD)이 아닌 이름으로 바꾸거나 날짜 아닌 노트를 옮겨 넣거나 폴더를 만들면 이유를 알리고 막는다. 이미 들어 있는 날짜 아닌 노트는 메모 탭 위쪽에 "날짜 이름이 아닌 노트 n개가 … 폴더에 있어요 [옮기기]"로 알리고, 누르면 이동 시트가 선택된 채로 열린다(날짜 폴더는 목적지에서 막힘). 폴더 설정이 비어 있으면(날짜 노트를 맨 위에 둠) 규칙을 적용하지 않는다.
- **프로젝트 폴더**(프로젝트/Projects): 바로 아래에 노트나 빈 폴더를 만들 수 없고 **새 프로젝트 마법사**로 안내한다(개요 노트까지 함께 만들어짐). 프로젝트 폴더 안의 노트는 자유. 프로젝트 노트(`type: project`)가 없는 프로젝트 폴더는 목록에 "프로젝트 개요 노트가 없어요 [개요 만들기]"를 보이고, 누르면 개요 노트를 만든다.
- 구현: `lib/folderRules.ts`(순수: 만들기·이동·이름 바꾸기 판정, 날짜 아닌 노트·개요 없는 폴더 찾기), 테스트 `folderOps.test.ts`. 폰에서 확인: 날짜 폴더 안의 이상한 이름 노트 안내 → 옮기기, Daily 에서 [쓰기] → 오늘 노트, 프로젝트 폴더에서 [쓰기] → 새 프로젝트, 개요 만들기.
- 한계: 규칙은 UI(메모 탭·새 노트/폴더 대화창·이름 바꾸기)에서만 적용되고, 저장소 수준(동기화·가져오기·AI 변경 제안)에서는 막지 않는다. PC 사이드바의 폴더 행에는 "개요 만들기"가 아직 없다.
