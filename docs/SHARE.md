# PC 폴더 보기 (PC 공유 폴더 · 읽기 전용 · HTTPS)

PC 앱이 지정한 **폴더 하나**를 같은 와이파이의 내 휴대폰이 읽기 전용으로 보고 내려받는다. 클라우드 계정이 필요 없다. 기본은 꺼짐.
AI 중계(`docs/RELAY.md`, 평문 http)와 **완전히 분리**: 별도 서버(기본 포트 47411)·별도 연결 코드·별도 기기 토큰이라, AI 중계 토큰으로는 파일에 닿을 수 없다.

## 연결
1. PC 설정 > 노트와 동기화 > "내 휴대폰에서 이 PC의 폴더 보기"를 켜고 **공유 폴더**를 고른다.
2. 폰 설정 > 노트와 동기화 > "PC 폴더 보기 (읽기 전용)"(v1.43.2 에서 "내 PC 폴더 보기"에서 이름을 바꿨다 — 노트를 맞추는 "내 PC" 연결과 헷갈려서): QR 스캔 또는 "연결 문자열 복사"로 복사한 글을 붙여 넣는다.
3. 연결 문자열 `nsf1:<ip,ip>:<port>:<6자리 코드>:<인증서 SHA-256 지문 64자>` — **지문이 들어 있어서** 지문 없이 연결하는 방법이 없다(짧은 코드 입력 방식 없음).

## 보안
- **HTTPS + 인증서 지문 고정**: PC 는 자체 서명 인증서(10년)를 만들어 보관한다(개인키는 OS 보안 저장소로 암호화). 폰은 안드로이드 `PinnedHttp` 플러그인(커스텀 TrustManager)이 서버 인증서 지문이 QR 의 값과 다르면 **요청을 보내기 전에** 끊는다. 지문이 비어 있거나 http 면 요청 자체를 거절.
- 짝 맺기: 코드 6자리·5분·한 번만, 5번 틀리면 1분 잠금, 기기 5대. 토큰은 PC 에 해시로만 보관, 20번 틀린 토큰은 잠시 차단. 기기별 해제는 PC 카드에서 즉시.
- **읽기 전용**: 서버에는 `/pair` `/ping` `/list` `/get` 과, 폰이 스스로 연결을 풀 때 쓰는 `/unpair`(토큰으로 인증된 기기가 **자기 자신만** 목록에서 지운다 — 폰의 `연결 해제`가 PC 의 "연결된 휴대폰"에서도 빠지게 한다)뿐이다. 쓰기·삭제·이름 바꾸기·실행·임의 경로 접근이 없다.
- **경로 방어**: 상대 경로만, `..` · 숨김(`.`로 시작) · `:`(드라이브·ADS) · 역슬래시 · NUL · 윈도 예약 이름(CON·NUL…) · 끝의 점/공백 거절. 목록에서 심볼릭 링크·정션은 빼고, 내려받기는 `realpath` 가 요청 경로와 다르면(중간에 링크가 있으면) 거절. 숨김 파일·`node_modules` 는 목록에서 뺀다. 한 파일 25MB.
- 공유 폴더로 지정할 수 없는 곳: 드라이브 루트, 홈 폴더 자체, 앱 데이터 폴더, 시스템 폴더.
- 받은 파일은 PC 가 보낸 크기·SHA-256 과 맞을 때만 건넨다(다르면 버림).
- **폰의 토큰 보관(v1.39.0)**: 연결 토큰은 Android Keystore(AES-GCM)로 암호화해 앱 전용 저장소에 둔다. 웹뷰 localStorage 에는 주소·지문·이름만 남고, 백업·기기 이전에서 제외한다. 상세: `docs/SECURE-STORAGE.md`.

## 코드
`electron/fileShare.cjs`(서버·인증서·IPC) · `ShareCard.tsx`(PC UI) · `src/lib/pcFiles.ts`(폰 클라이언트) · `pinnedHttp.ts` + `PinnedHttpPlugin.java`(지문 고정 전송) · `PcFilesCard.tsx`(폰 UI·파일 시트).
시험: `fileShare.server.test.ts`(실제 HTTPS 서버, 임시 폴더, 정션·심볼릭 링크, 우회 경로) · `pcFiles.test.ts`(폰 클라이언트↔서버, 지문 불일치·변조 감지).

## 이번 단계에서 하지 않는 것 (장기 과제)
- **로컬 Vault 동기화는 아니다.** 지금 Vault 의 Markdown 은 앱 내부 저장소(IndexedDB)에 있고 일반 파일 원본은 클라우드에만 있다. 이 기능의 공유 폴더는 별개의 저장소라서, 그대로 두면 "Vault 와 공유 폴더"로 데이터가 갈라진다.
- 목표: PC 를 로컬 동기화 호스트로 써서 Markdown 과 일반 파일을 클라우드 없이 PC·폰이 공유한다. 그러려면 **Vault 의 파일 저장·동기화 계층을 통합**해야 한다(예: Vault 를 PC 폴더에 두고 노트·파일을 같은 Provider 인터페이스(`list/read/push`) 뒤에 두기 — 지금의 GitHub·Drive·OneDrive Provider 와 나란히 "내 기기끼리" Provider 를 추가). 양방향(쓰기)·충돌 처리·삭제 전파는 그 단계에서 설계한다.
- 기존 클라우드 동기화는 유지한다.
- 위 통합의 상세 설계(권한 모델·rev·조건부 쓰기·충돌·최초 연결 미리보기·오프라인 원칙·주소 재탐색)는 `docs/SYNC-HOST.md`.
