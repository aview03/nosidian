# 릴리스 체크리스트

## 배포 전
1. `main`에서 릴리스 브랜치 생성: `git switch -c release/2.3`
2. 변경 로그 정리, 버전 올리기
3. 회귀 테스트(자동) 통과 확인
4. 스테이징 카나리 24시간

## 배포 명령
```bash
git tag -a v2.3.0 -m "v2.3.0"
git push origin release/2.3 --follow-tags
./gradlew :app:bundleRelease
fastlane ios release
```

## 롤백
```bash
# 문제 발생 시 이전 태그로 되돌리기
git revert --no-edit v2.3.0
kubectl -n payments rollout undo deploy/gateway
```
